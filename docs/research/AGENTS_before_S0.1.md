Без NAT traversal/STUN/TURN, публичных серверов и matchmaking. Независимые player states, общий сюжетный прогресс, Shared Achievement Progress для всех 20 оригинальных Steam-достижений с учётом участия в событиях. Опции предметов/Power-Ups/FF/respawn/scaling предусмотреть как расширение, подробно сейчас не разрабатывать.

Исследовательский handoff завершён. По последнему разрешению пользователя активен экспериментальный M0: сначала M0-A, M0-B, после проверки runtime адресов/ABI/lifetime — M0-C. Не исправлять REA MCP и не повторять общий реверс. Full Player основной кандидат; Proxy не считать готовым и оценивать лишь при конкретном блокере M0-C.

Пользователь разрешил runtime эксперименты M0, диагностические инструменты, C++ исходники и экспериментальную DLL **только внутри этой папки и отдельной тестовой копии/профиля**. Оригинальная установка, пользовательские сохранения и референсы остаются read-only. Не реализовывать сеть, не подключать ENet, не изменять Steam-достижения. Запуск и instrumentation допустимы только для проверенной копии игры в рабочей папке. Не memcpy игровых структур и не записывать указатели произвольно; использовать доказанные native lifecycle contracts. Сохранять raw logs, ошибки, выводы и точное воспроизведение каждого опыта.

Перед продолжением читать `docs/PROGRESS.md`, `docs/EVIDENCE_INDEX.md` и `docs/10_OPUS_HANDOFF.md`, если они существуют. Сверять SHA-256 целевого бинарника; использовать уже сохранённые результаты при совпадении хеша и профиля анализа. Не повторять идентичные неуспешные вызовы без изменения условий.

Метки: VERIFIED = проверенное статическое наблюдение с конкретным Evidence; INFERRED = вывод/гипотеза; UNKNOWN = не установлено. Статическое наблюдение не доказывает поведение во время исполнения. Псевдокод декомпилятора не является исходным кодом. Исходники PowerSlave EX 2015, SlaveDriver, PSEPSX, Raze не считать исходниками KEX 2022.

Для функций указывать бинарный SHA-256, VA/RVA/file offset отдельно, Evidence, наблюдаемые связи, ограничения, неизвестные аргументы/ABI и значение для кооператива. Имена аналитика отделять от восстановленных имён. Никаких вымышленных адресов, полей, сигнатур или подтверждений работы.

Крупные результаты сохранять отдельно в `docs/evidence/`, в контекст выводить выборки и сводки. Исторические инструменты — в `docs/research/`; M0 исходники/сборки/профили — в `experiments/m0/`, логи/Evidence — в `docs/evidence/m0/`. После законченного блока обновлять PROGRESS и индекс. M0 успешен только после runtime проверки двух независимых персонажей: lifecycle, movement/collision, weapon/damage и безопасное уничтожение без повреждения первого Player. Рендер второй копии или два выделенных объекта не являются успехом.
