# П27 — переносимая установка мода в игру (предложение)

2026-11-07. **Статус: предложение, TODO.** Номер DOC не занят намеренно: присвоить при выпуске отчёта исполнения. Режим приёмки **В**, исполнитель ≠ проверяющий. Не PASS и не отчёт о выполнении.

## Зачем

Сейчас друзьям можно отдать только диагностический ZIP ([П25](../experiments/pse_together/packaging/README.md), батник `make_friends_zip.bat` в корне мода): standalone ENet, логи, дампы. Сам мод в KEX у друга не запустится:

| Блокер | Факт |
|---|---|
| Два жёстких пути | broker принимает только два точных пути рабочего стенда ([DOC-69](69_P24_PROXY_DLL_LOADER.md), `loader_common.hpp`) |
| Изоляция профилей — это Frida | KnownFolder/early-path redirects и bounded write-open guard ставит REA/Frida (`generated_isolation.js`), не сам мод. У друга ни REA, ни Frida |
| Нет выдачи permit | loader не вызывает `M11PermitTest` / `PSE_P1_PermitProxySpawn`; gameplay включал стенд |
| Нет игровой установки | friends-набор не содержит игры (и не должен) и не копирует её; чистая машина не проверялась ([П25 PARTIAL](ROADMAP.md)) |
| Нет KEX-логов/дампов | supervisor П25 покрывает только собственные ENet EXE |

Побочная польза: П27 снимает зависимость П5 (тест на двух ПК) от «стенда REA на втором ПК».

## Предлагаемая модель установки

**Копия игры, как в тестовых копиях стенда, а не правка Steam-установки.** `install.bat` проверяет SHA-256 EXE друга (`b8f131…a76d`, [DOC-83](83_P24_INDEPENDENT_ACCEPTANCE.md)), копирует 77 файлов игры из его Steam-папки в `<папка мода>\game`, кладёт туда shim `SDL2.dll`, `SDL2_pse_original.dll`, `pe-together.dll`, `pse-runtime.dll`, `pe-together.ini`. Оригинальная установка, Steam-сохранения и достижения друга не изменяются. Ресурсы игры в архив не входят; игра должна быть куплена у каждого друга.

Это принятая в проекте схема независимых копий (DOC-51/П24), поэтому риск ниже, чем у установки поверх Steam. Обновление Steam, меняющее EXE, ломает совместимость — это сообщает SHA gate (RU/EN), поддержка нескольких версий не планируется.

## Границы и риски

- Это native-работа вне принятого шаблона (загрузчик, изоляция записи, permit), поэтому режим В; пересборка DLL — при пересборке DLL сверять 7/7 секций с эталоном (`tools/dll_compare.py`; линковать с точным `/PDBALTPATH`, иначе сравнение ложно падает по длине пути PDB) и никогда не собирать в `b60`.
- Native write guard — не полный OS sandbox (прямые syscalls, унаследованные handles, rename API): ограничения [DOC-69](69_P24_PROXY_DLL_LOADER.md) сохраняются и должны быть сказаны друзьям в README.
- Steam: достижения не трогаются (D4 остаётся запретом). В копии игры ожидается прежнее `Unable to initialize Steam`; успешная инициализация Steam не цель.
- Wire v1.10–v1.13 не менять. Игровой геймплей П27 не расширяет.
- Не повторять принятые прогоны: loader smoke П24 засчитан, нужны только новые условия (без Frida, чужая папка).
