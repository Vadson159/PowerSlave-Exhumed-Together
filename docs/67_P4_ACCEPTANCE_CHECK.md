## 3. Код

**Что в порядке.** Новые нативные пути закрыты `PSE_FEATURE_P4`; исключение — F1. В links, refs, flags и кэши пола и потолка запись не идёт. LinkSector вызывается только после проверки exact16-префикса и membership 1/0 до вызова и 0/1 после. Буфер хранит POD-копии без указателей и очищается на Remove и worldExit. Перепись акторов на хосте только читает: списки секторов проверяются по ссылкам в обе стороны, длина ограничена. Фоновый режим клиента повторяет принятый хостовый шаблон DOC-53: аренда байта фокуса +0x319 с серийным номером события, обнуление только блока команд `0..0x7c`, проверка вызывающего Update до оригинала, восстановление Update/Commands/Turning по exact16. По умолчанию он выключен, включается атомарным экспортом.

**Находки.** F2 блокирует S1.5; остальные не блокируют, но их нужно закрыть до следующей приёмки.
