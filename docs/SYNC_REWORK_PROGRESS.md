# Переделка синхронизации (ветка `sync-rework`)

Начато 2026-11-11. Ход работы ведёт агент; пользователь проверяет только итог.

## Цель

- Одна сетевая сессия хоста на всю игру (до выхода хоста), клиенты не переподключаются при смене мира.
- Один мир — у хоста; клиент грузит ту же карту, но логику мира не выполняет, а показывает состояние хоста общими каналами.
- Владение: что делает мой игрок (движение, касания, «использовать», урон от окружения, попадания) — решает мой клиент и сообщает хосту; всё остальное — хост.

## Этапы

| # | Этап | Статус |
|---|------|--------|
| 1 | Единая сессия хоста (смена мира = новая привязка карты/epoch внутри сессии) | готов, проверен вживую |
| 2 | Общий перехват действий своего игрока у клиента (касание, «использовать», урон) — один канал | в работе |
| 3 | Общая репликация акторов уровня, локальная логика мира у клиента выключена | не начат |
| 4 | Репликация секторов (пол/потолок/свет) и граней (текстуры рычагов) | не начат |
| 5 | Удаление лишних частных пересылок | не начат |
| — | Финал: полный регресс, пакет друга, S:\PSE_Together, отчёт | не начат |

## Этап 1 — единая сессия хоста

Сделано в коде:
- `m12a::Session` хоста живёт весь процесс: `unbind("StateExit")` зовёт `leaveWorld()` (все клиенты остаются подключены, но не готовы),
  остановка — только при выходе из игры (DirectQuit) или неустранимом сбое процесса.
- Следующий мир: вместо новой сессии — `rebindNativeMap(identity, новый epoch)`: все HostGate перепривязываются, клиентам уходит
  MapChange с `newMapEpoch != 0` (BROADCAST: рабочий поток сети обновляет карту WELCOME и фильтр epoch снимков).
- Тайм-аут входа (600 тиков без MapReady) считает только тики, когда хост в игре, и только для нового соединения:
  клиент, бывший готовым, не выкидывается, пока грузится или выбирает на карте мира.
- Повторный MapReady того же epoch (мир клиента перезапустился сам, у хоста — нет) = «повторная готовность»: базовая линия и общее
  состояние мира (joinSerial) заново, тело у хоста продолжает жить.
- Сервер: слот давно ушедшей личности (отключена > 60 с) отдаётся новичку (поколение слота растёт дальше); короткий обрыв слот держит.
- Клиент: `ENetClientNode::setSessionMap` при MapChange нового epoch (фильтр снимков), ввод ждёт MapReady нового мира.
- Клиент: Session переживает `worldTransition` (если соединение живо): сбрасываются только мировые защёлки (прокси, респаун P16, P7),
  `ClientGate::newWorld()`; новая привязка хоста (`ClientGate::mapChange`) — без блокировки; несовпадение уровня с хостом больше
  не терминально — клиент следует за уровнем хоста (`followCheck`: один раз на новую привязку, чтобы не вернуть клиента назад,
  пока хост сам ещё между мирами). Приказы хоста, полученные до ухода из мира, при уходе отбрасываются.

Проверено оффлайн:
- сборка без предупреждений; ctest 18/19 (`p24_loader_contract` — как всегда);
- `multi_peer_live`: новый раздел 9 (7 клиентов): leaveWorld → 900 тиков вне игры без выкидывания → rebind → у всех MapChange с новым
  epoch в том же соединении → старый MapReady отвергнут, новый принят → базовая линия нового мира → снимки нового epoch доходят →
  ввод → повторная готовность → переподключение после смены мира получает новый мир в WELCOME (170 проверок).

## Заметки разведки для этапа 2 (EXE b8f131…, RVA)

- Общая точка касания актора: `0x1a4990(rcx, Actor* mover = rdx, r8)` — проход по акторам секторов при движении `mover`.
  Внутри (`0x1a596f`) берёт флаги касаемого `+0x16c` (0x2 solid, 0x100 touchable), проверка расстояния, затем
  `0x1a5a84: mov rax,[rbx]; mov rdx,r15; mov rcx,rbx; call [rax+0x40]` = `touched->OnTouch(mover)`.
  Вызывающие: `0x19f2d0` (физика актора, 0x19f7ed), `0x1a1530`, `0x1dc6e0`, `0x1dd670`, `0x1ddf70`, `0x1de8b0`.
- Сам вызов виртуальный: перехватывать либо входом `0x1a4990` (область «двигается свой игрок») + детуры реализаций OnTouch
  (+0x40 классов с флагом 0x100, известные: здоровье 0x1d8770, патроны 0x1d8590, скарабей 0x1a3b50, ключ/оружие/анкх — vtable 0x52c998/0x52cb60/0x52c7d0).
- Инструменты разведки: `tools/re/xdis.py <rva> [n]` / `xdis.py find <regex> [window-regex]` и `tools/re/xfunc.py <rva>...` (capstone+pefile; EXE play_vote).
- OnTouch (+0x40) по vtable: здоровье 0x52c868→0x1d8770, патроны 0x52cac8→0x1d8590, анкх 0x52c7d0→0x1d8870, ключ 0x52c998→0x1d8a00,
  оружие 0x52cb60→0x1d8470, скарабей 0x5288f0→0x1a3b50, выход TravelObject 0x530588→0x2072e0, Puppet игрока 0x52d198→0x4a670 (базовый, пустой?).
