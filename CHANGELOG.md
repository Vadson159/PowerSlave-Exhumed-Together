# CHANGELOG

## 2026-11-08 — схлопывание форков в один бинарник

- Протоколы `wire111/112/113` → один `src/net` (версия v1.13: нативная идентичность карты, состояние игрока P7,
  чат/лобби P23). Добавлен единый `net_protocol.h`.
- `host_p7/p16/p23.cpp` → один `host.cpp` (трёхстороннее слияние: P7 + respawn/weapon pickup P16 + меню/HUD/автокарта P23).
  `client_p7/p16/p23.cpp` → один `client.cpp`. Три `network_input*.cpp` → один; обработчик respawn регистрируется
  хостом (`m12a::respawnHandler`), без символа-призрака между библиотеками.
- Одна DLL `pse_together.dll`: `dll_main.cpp` экспортирует `M11Prepare`/`M11PermitTest`/… и по `PSE_ROLE` передаёт
  управление `host_*` или `client_*` (два файла, приватное состояние). Загрузчик (broker v2) и `p27.py install` берут
  `pse_together.dll`, в `pe-together.ini` один `[payload] sha256=`.
- CMake: вместо 16 `pse_dll_*` и 33 тестов — `pse_together`, загрузчик и 11 тестов, которые отражают реальный код
  (respawn, self-state, weapon pickup, автомат прокси 58B/58B.1/58B.2, bounded proxy, P4 presentation, UI-кодек,
  lobby на реальном ENet).
- Удалены обёртки REA/Frida (`tools/runtime_*`, `pre_native_*`, `audit_*`, …), мок-тесты старых wire-версий.
- Не вошло в эту сборку: реконнект прокси при смене карты (P3) лежит в `experiments/pse_together/p3_reconnect/`,
  не собирается — слияние дало конфликт всей архитектуры `Session` (процесс-живой роутер + сессия на мир);
  P14 (ИИ врагов выбирает среди игроков) и P8 (спрайты) выключены; тесты сессии «headless domain» удалены —
  Welcome v1.13 требует нативную идентичность карты, их надо заменить одним тестом host+client.
- Состояние до схлопывания: git-тег `pre-collapse`.

## 2026-11-08 — smoke test объединённого бинарника (два процесса, один ПК, TOMB)

хуки восстановлены, оригинал игры и Saved Games не изменены. Нюансы: P2 спавнится, только когда хост-P1 отошёл от якоря
(~>93 ед.) в течение 1800 тиков; прокси хост-P1 на клиенте отказывает (`P4_SPAWN_AABB_OUTSIDE_SECTOR`), когда P1 стоит у границы сектора 259.

## 2026-11-08 — спавн P2 рядом с хостом, прокси в любом секторе, P14 и P8 включены

- **Спавн P2 (host.cpp):** фиксированный якорь спавна и тайм-аут 1800 тиков убраны. P2 ставится справа/слева/сзади от
  *текущей* позиции хост-P1 (96→140 ед.) в его секторе: native point-in-sector, те же floor/ceiling, read-only перепись акторов;
  пробуется каждый тик, пока место не свободно. Лог: `p4_spawn_chosen`.
- **Прокси хоста на клиенте (native_proxy.cpp):** убраны привязка к TOMB (имя/счётчики) и к сектору 259 (аттестация всех
  секторов карты), `P4_SPAWN_AABB_OUTSIDE_SECTOR` и отказы по апертуре. Нет верифицированного коридора между секторами
  или другая высота пола/потолка → relocate: native `LinkSector` + сброс интерполянта + обновление floor/ceiling-кэша
  родными функциями высоты (лог `p4_relocated`). Клиент видит спрайт хост-игрока (подтверждено скриншотом).
- **P8 включён** (`PSE_FEATURE_P8`, #error в config.hpp снят): третье лицо для прокси клиента и анимация для P2 на хосте.
  `p27.py install` кладёт `coop_sprites_john.kpf` в `game/mods/` (KEX монтирует `mods/*.kpf`).
- **P14 включён** (ИИ врагов выбирает цель среди игроков): исправлен F1 — при потере права (нет живого P2, сбой) хуки
  Idle/Chase/Health/Ammo вызывают оригинал, а не замирают. Тест `p14_gameplay_contract` обновлён (65793 проверок).
- **Тулинг:** `p27.py install` сам берёт свежайший билд-каталог (`b*/p27` + `b*/dll/pse_together.dll`), env не нужен.
  Новое: `tools/smoke.py` — двухпроцессный прогон с меню, ходьбой, скриншотами и сводкой логов.
- **Известные пробелы:** хост НЕ видит P2 (Player-актор в мире не рисуется; анимация привязывается, но спрайта нет —
  нужен хост-прокси для P2 или выяснение условия рисования); реконнект p3 по-прежнему в `p3_reconnect/`, не интегрирован
  (Restart Level / Reload Checkpoint пока не переживаются); иногда прогон не стартует из-за таймингов меню.

## 2026-11-08 — Веха 1: обоюдная видимость и перезапуск уровня

- **P2 виден на хосте.** Player-актор мира не рисуется (scale/flags у Puppet такие же, как у P1: 1.0 / 0x20200022), поэтому
  хост показывает P2 тем же механизмом, что клиент показывает хоста: пассивный актор 1007 со спрайтом John
  (`native_proxy.cpp` в `hostMode`, `SnapshotRouter<1>` на слот 1, обвязка в `host.cpp`: `proxyRoute/proxyPhase/proxyExit`).
  Puppet больше не получает анимацию P8. Родной хук puppet-tick хост оставляет себе и пересылает в `notePuppetTick()`.
- **Перезапуск уровня / чекпоинт / StateExit на клиенте больше не тупик.** Вместо порта лаборатории p3 (RearmRouter,
  teardown-witness из 4 хуков) сделан короткий путь: `worldTransition()` — барьер прокси, остановка старой Session,
  сброс всех per-world защёлок (P7 authority, P16 respawn gate), `native_proxy::rearm()`, новая Session на следующем
  стабильном gameplay-мире с сохранённым reconnect-key. Хуки остаются, терминален только DirectQuit; UI Together не
  сбрасывается. Хост при новом поколении клиента делает `rearm()` и заново спавнит прокси P2 (`proxy_rejoin_rearmed`).
  Проверено живьём: Restart Level на клиенте → `world_transition`, `client_session` 2, прокси на обеих сторонах заново.
  Не портировано из p3: teardown-witness и anti-ABA (опираемся на проверенную DOC-58B.2 очистку движком).
  `p3_reconnect/` удалён (история — тег `pre-collapse`).
- `tools/smoke.py`: `SMOKE_SWEEP=1` (обзор мышью), `SMOKE_RESTART=1` (Restart Level через паузу + повторная проверка видимости),
  `SMOKE_MENU=1`.
