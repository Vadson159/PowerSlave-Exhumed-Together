# PowerSlave Exhumed Together

Co-op для PowerSlave Exhumed (KEX 2022, EXE SHA-256 `b8f131037187ca8d0a282527fb6f55a2012241d5b9dac8bf2038baf35b71a76d`):
2–8 игроков, хост авторитетен (listen server), LAN / Radmin VPN, ENet.

## Правила работы (с 2026-11-08, KISS / YAGNI)

1. **Одна кодовая база.** Один `host.cpp`, один `client.cpp`, один протокол `src/net/include/net_protocol.h`, одна DLL
   `pse_together.dll` (роль — переменная `PSE_ROLE=host|client`). Никаких копий вида `host_pNN.cpp` / `wireNNN`;
   изменения вносятся в основной код, история — в git (`pre-collapse` — тег состояния до схлопывания).
2. **Протокол — только то, что используется сейчас:** игроки (позиции, углы, состояние), ввод, смена карты, чат/лобби,
   далее двери/триггеры и враги. Структуры «на будущее» не создаём.
3. **Без бюрократии:** режимы приёмки, пакеты, DOC-отчёты и «независимые приёмки» отменены. Документация — понятные
   коммиты, `CHANGELOG.md` и комментарии в сложных местах кода.
4. **Готово — это игра:** двое запускают игру по сети, видят друг друга, вместе нажимают рычаг/дверь, убивают врага и
   переходят на следующий уровень кампании без вылета. Тесты — вспомогательные (`ctest`), не цель.

## Техника безопасности (не бюрократия)

- Оригинальную установку Steam, сохранения пользователя и достижения не менять; запуск — на копии игры (`p27.py install`).
- Не трогать память игры произвольными записями: нативные вызовы движка и скалярные записи в известные поля, свой код на
  Sim-потоке. Указатели и адреса по сети не передаются.

## Сборка и запуск

```
cmake -S experiments/pse_together -B b97 -G "Visual Studio 17 2022" -A x64
cmake --build b97 --config Release --target pse_all      # pse_together.dll + загрузчик (pe-play, SDL2-shim, broker)
cmake --build b97 --config Release --target pse_tests && (cd b97 && ctest -C Release)
python -X utf8 -B experiments/pse_together/tools/p27.py install <новая папка>   # копия игры + host.bat / join.bat
```

Короткий каталог сборки (`b97`, не вложенный глубоко) — иначе MSBuild упирается в MAX_PATH.
Старые отчёты `docs/NN_*.md`, `ROADMAP`, `PROGRESS` — архив, справочные.
